### 1. 基本连续时间信号
| 信号名称 | 表达式 |
|----------|--------|
| 单位阶跃 | $$u(t) = \begin{cases} 1, & t > 0 \\ 0, & t < 0 \end{cases}$$ |
| 单位冲激 | $$\delta(t) = 0 \ (t \neq 0), \quad \int_{-\infty}^{\infty} \delta(t)\,dt = 1$$ |
| 斜坡信号 | $$r(t) = t\,u(t)$$ |
| 复指数信号 | $$e^{s t}, \quad s = \sigma + j\omega$$ |
| 正弦信号 | $$x(t) = A \cos(\omega_0 t + \phi)$$ |

---

### 2. 基本离散时间信号
| 信号名称 | 表达式 |
|----------|--------|
| 单位阶跃序列 | $$u[n] = \begin{cases} 1, & n \ge 0 \\ 0, & n < 0 \end{cases}$$ |
| 单位脉冲序列 | $$\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases}$$ |
| 指数序列 | $$x[n] = a^n u[n]$$ |
| 正弦序列 | $$x[n] = A \cos(\Omega_0 n + \phi)$$ |

---

### 3. 卷积
| 类型   | 公式                                                                         |
| ---- | -------------------------------------------------------------------------- |
| 连续卷积 | $$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,d\tau$$ |
| 离散卷积 | $$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k]\,h[n-k]$$            |

---

### 4. 连续时间傅里叶级数 (CTFS)
| 形式 | 公式 |
|------|------|
| 指数形式 | $$x(t) = \sum_{k=-\infty}^{\infty} a_k e^{j k \omega_0 t}, \quad a_k = \frac{1}{T} \int_{T} x(t) e^{-j k \omega_0 t} dt$$ |
| 三角形式 | $$x(t) = a_0 + \sum_{n=1}^{\infty} \bigl[ a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t) \bigr]$$ |

---

### 5. 连续时间傅里叶变换 (CTFT)
| 变换对 | 公式                                                                                  |
| --- | ----------------------------------------------------------------------------------- |
| 正变换 | $$X(j\omega) = \int_{-\infty}^{\infty} x(t) e^{-j\omega t}\,dt$$                    |
| 逆变换 | $$x(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j\omega) e^{j\omega t}\,d\omega$$ |

---

### 6. 拉普拉斯变换 (单边/双边)
| 变换对 | 公式 |
|--------|------|
| 正变换（单边） | $$X(s) = \int_{0^{-}}^{\infty} x(t) e^{-s t}\,dt$$ |
| 逆变换 | $$x(t) = \frac{1}{2\pi j} \int_{\sigma-j\infty}^{\sigma+j\infty} X(s) e^{s t}\,ds$$ |
| 双边变换 | $$X_{\text{BI}}(s) = \int_{-\infty}^{\infty} x(t) e^{-s t}\,dt$$ |

---

### 7. Z 变换
| 变换对 | 公式 |
|--------|------|
| 正变换（双边） | $$X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$ |
| 正变换（单边） | $$X(z) = \sum_{n=0}^{\infty} x[n] z^{-n}$$ |
| 逆变换 | $$x[n] = \frac{1}{2\pi j} \oint_{C} X(z) z^{n-1}\,dz$$ |

### 9. 傅里叶变换常用性质
| 性质 | 时域 | 频域 |
|------|------|------|
| 线性 | $$a x_1(t) + b x_2(t)$$ | $$a X_1(j\omega) + b X_2(j\omega)$$ |
| 时移 | $$x(t - t_0)$$ | $$e^{-j\omega t_0} X(j\omega)$$ |
| 频移 | $$e^{j\omega_0 t} x(t)$$ | $$X(j(\omega - \omega_0))$$ |
| 尺度变换 | $$x(at)$$ | $$\frac{1}{|a|} X\!\left(j\frac{\omega}{a}\right)$$ |
| 卷积定理 | $$x_1(t) * x_2(t)$$ | $$X_1(j\omega) X_2(j\omega)$$ |
| 乘积定理 | $$x_1(t) x_2(t)$$ | $$\frac{1}{2\pi} [X_1 * X_2](j\omega)$$ |
| 微分 | $$\frac{d^n x(t)}{dt^n}$$ | $$(j\omega)^n X(j\omega)$$ |
| 积分 | $$\int_{-\infty}^{t} x(\tau) d\tau$$ | $$\frac{1}{j\omega} X(j\omega) + \pi X(0)\delta(\omega)$$ |
| 对称性 | $$X(t)$$ | $$2\pi x(-\omega)$$ |
